# Final_IoT

This project aims to start the intergation process of a home with smart devices. A temperature and humidity sensor and a motion sensor send data to MQTT topics. That data can be looked over through MQTTX. A relay serves as a simulated connection between the house's lights, and can be turned on or off to reflect turning the lights on or off. Wokwi is used to simulate the devices and data. The project results in devices connected together which can publish data to MQTT topics, and a MQTTX connection that can view that data and send a command to the devices.
